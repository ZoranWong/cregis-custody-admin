> 依据：Data-Dense Dashboard（BI/企业报表风格，Light ✓ / Dark ✓ 双模完整）适用范围：`src/views/**`、`src/components/**` 状态：规范已定稿，存量代码处于「部分落地」状态（详见 §7）。落地进度以本文为准，**新增代码必须遵守，存量按 §8 分批收敛**。

## 0. 从 ui-ux-pro-max 生成结果中「不采用」的部分（重要）

用 `--design-system` 生成的初版 MASTER 推荐了 `#F59E0B` 金 + `#8B5CF6` 紫 + Fira Code + 深色 Hero/CTA 落地页版式。**本项目不采用**，理由：

| 生成项 | 不采用原因 |
| --- | --- |
| Primary `#F59E0B` 金 | 那是「营销落地页/加密交易 C 端」的信任色。本项目是**内部运营后台**，且已有既定品牌绿 `#00BE78` |
| 深色背景 `#0F172A` 为基底 | 本项目**浅色为主**、深色为可选模式，不是 OLED 深色优先 |
| Hero → Metrics → CTA 版式 | 那是落地页结构，后台没有 Hero/CTA |
| Fira Code / Fira Sans | 引入新字体族会造成全站字体变更，收益低于成本；沿用现有系统字体栈 |

**采用的部分**：Data-Dense Dashboard 风格本体、Financial Dashboard 的 `On Primary` 深色前景模式（§1.2 的关键决策）、8px 间距节奏、反模式清单。

## 1. 颜色

### 1.1 文字层级（唯一的正文色来源）

**禁止**把 `g-100`~`g-400` 用作文字 —— 它们是背景/边框色阶，白底对比度仅 1.2–1.3:1。

| 用途 | Token | 浅色值 | 对比度 | 深色值 | 对比度 |
| --- | --- | --- | --- | --- | --- |
| 主要（标题/核心数据） | `text-g-900` | `#323251` | 12.28:1 | `#e3e3e8` | 14.13:1 |
| 次级（表单标签/辅助信息） | `--tone-secondary-text` | `#4d5875` | 7.07:1 | `#ababba` | 7.97:1 |
| 弱化（地址/时间戳/来源） | `--tone-muted-text` | `#64748b` | 4.76:1 | `#94a3b8` | 6.2:1 |
| **禁用** | ~~`text-g-500`~~ | `#949eb7` | **2.68:1** ✗ | `#73738c` | 3.92:1 ✗ |

**表头**统一走 `--tone-secondary-text`，不再使用 Element 默认的 `#909399`（3.08:1 ✗）。

### 1.2 品牌色（关键决策：不改品牌色，改前景色）

品牌绿 `#00BE78` 作底、白字时仅 **2.43:1** ✗。**不要**通过加深绿色来修（会偏离品牌），而是采用 Financial Dashboard 的 `On Primary` 模式 —— **深色前景**：

| 场景                       | 取值                          | 对比度        |
| -------------------------- | ----------------------------- | ------------- |
| 主按钮 / 实心标签          | 底 `#00BE78` + 文字 `#0F172A` | **7.34:1** ✓✓ |
| 浅色模式下的文字/图标/链接 | `#0F7350`                     | **5.85:1** ✓  |
| 深色模式下的文字/图标/链接 | `#00BE78`（原色即达标）       | **7.43:1** ✓  |

> 结论：`#00BE78` 在浅色模式**只做底、不做字**；做字时用 `#0F7350`。

### 1.3 状态语义（唯一实现：`--tone-*`）

六态：`done` / `progress` / `error` / `info` / `neutral` / `purple`，每态三个槽位：

| 槽位                  | 用途      | 要求                    |
| --------------------- | --------- | ----------------------- |
| `--tone-{state}-text` | 文字      | ≥4.5:1                  |
| `--tone-{state}-mark` | 圆点/形状 | ≥3:1                    |
| `--tone-{state}-bg`   | 底色      | 必须与 `-text` 配对使用 |

**禁止**：`text-[var(--el-color-success)]`、`text-success`、`color: var(--el-color-danger)`、 `bg-[var(--el-color-*-light-N)]` —— 这些在暗色模式下不翻转（`el-dark.scss` 无对应覆盖）。

### 1.4 暗色适配

- 容器底色一律用 `var(--default-box-color)` / `bg-box`，**禁止 `bg-white` / `#fff`**。
- 所有颜色必须来自变量，保证明暗两套自动切换。
- 新增颜色时必须同时在 `:root` 与 `.dark` 两处定义。

## 2. 字体

### 2.1 字号刻度

| Token | 值 | 用途 | 备注 |
| --- | --- | --- | --- |
| `text-caption` | 10px | 全大写微标签 | 需配 `uppercase + tracking` |
| `text-label` | 11px | 徽章、辅助标签 |  |
| `text-body` | 12px | 次级正文：地址、时间、说明 |  |
| `text-body-lg` | 13px | 主正文：步骤标题、说明 |  |
| `text-title` | 15px | 卡片/区块标题 |  |
| `text-metric` | 16px | 列表金额、KPI 数字 |  |
| `text-hero` | 20px | 页面 h1、详情页主金额 |  |
| **`text-display`（新增）** | **24px** | **KPI 大数字** | 对应原型 `.mc-value`；**本档为刻度缺口补齐** |

**禁止** `text-[Npx]` 任意值；**禁止** 9px（低于可读下限）。

> 依据：KPI 数值实测分布 18/20/22/24/26/30px —— 原刻度（最高 20px）**没有任何一档能覆盖 KPI**，所以之前 14 处 KPI 全部是「刻度外」。补 `display: 24px` 后即可归一。

### 2.2 字重角色（四级，禁止跨级）

| 值  | 唯一职责                                                        |
| --- | --------------------------------------------------------------- |
| 700 | 仅全大写微标签（uppercase + tracking 已损失可读性，需加重补偿） |
| 600 | 全部标题、卡片标题、状态文字、徽章、数字                        |
| 500 | 标签、按钮、次级强调                                            |
| 400 | 正文                                                            |

### 2.3 行高与字距

- 正文 `line-height: 1.5`；KPI 大数字 `1.1`。
- 全大写微标签统一 `letter-spacing: 0.04em`（现状有 0.2/0.08/0.05/0.04/0.03 五种，需收敛）。

## 3. 图标

尺寸一律走 `text-icon-*`，**不得依赖继承**（`ArtSvgIcon` 以 `font-size` 驱动渲染）：

| Token          | 值   | 用途         |
| -------------- | ---- | ------------ |
| `text-icon-xs` | 12px | 微标签内图标 |
| `text-icon-sm` | 14px | 按钮内图标   |
| `text-icon-md` | 16px | 常规         |
| `text-icon-lg` | 18px | 流向箭头     |
| `text-icon-xl` | 24px | 首屏方向     |

**禁止** `text-lg/xl/2xl` 等字号类驱动图标。

---

## 4. 间距

8px 节奏：`4 / 8 / 12 / 16 / 20 / 24 / 32`。

| 场景       | 取值                                       |
| ---------- | ------------------------------------------ |
| 卡片之间   | **`mb-5`（20px）** ← 全站统一，废弃 `mb-4` |
| 卡片内边距 | `p-4`（16px）/ `p-5`（20px）               |
| 图标与文字 | `gap-2`（8px）                             |
| 区块内元素 | `gap-3`（12px）                            |

**禁止**：`mt-30`、`p-16`、`gap-3.5`、`ml-[34px]` 等离群值。

## 7. 反模式清单（禁止）

- ❌ 用 `width` 写满所有 `el-table-column`（无 `min-width` 列 → 表格宽度=列宽之和，右侧留白）
- ❌ `text-g-500` / `text-g-400` 作正文
- ❌ `text-[Npx]` 任意字号、9px 字号
- ❌ `text-[var(--el-color-*)]` / `text-success` / `bg-[*-light-N]` 作状态色
- ❌ `bg-white` / `#fff` 作容器底色（暗色下不翻转）
- ❌ 表头文字用 Element 默认色
- ❌ 模板里硬编码中英文文案（必须 `$t()`）
- ❌ 复制粘贴 KPI 卡 / 卡片头结构
